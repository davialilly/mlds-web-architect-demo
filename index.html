Standards

Accessibility statement

Conformance target

This page is built to conform to WCAG 2.1 Level AA, consistent with Section 508 and the U.S. Web Design System (USWDS) baseline MLDS Center already follows.

What this page does

  • Semantic landmarks (header, nav, main, section, footer) and one <h1> per page
  • A skip-to-content link as the first focusable element
  • A real, always-visible data table as the source of truth; the chart is a visual supplement, not a replacement
  • Color contrast checked at 4.5:1 or better for body text against its background
  • Visible keyboard focus states on every interactive element
  • No content that relies on color alone to convey meaning
  • Respects prefers-reduced-motion

Data handling

Data & privacy (FERPA alignment)

What this demo uses

Every figure on this page comes from data/enrollment-trends.json, a synthetic, district-aggregate file created for this exercise. It contains no student names, IDs, dates of birth, or any other individually identifiable information, and no data small enough in count to allow re-identification.

How this reflects FERPA in production

  • Public-facing pages and dashboards show aggregate data only, never student-level records
  • Aggregate cells below a minimum reporting threshold are suppressed rather than shown as small numbers
  • Any dashboard requiring student-level detail sits behind authenticated, role-based access, not on a public page
  • Source data pipelines and access are documented separately from the public site; see README.md
